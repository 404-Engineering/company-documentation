SHEET 02

Following Drone

404-Engineering/Following-Drone ↗

A quadcopter that follows the jeep on off-road trails and builds 3D maps of the trail with an onboard ZED stereo camera. A Jetson Orin Nano handles mapping and follow logic; Raspberry Pi Pico 2 modules run the flight controller, radio and sensors, all on one CAN bus. A comm board in the jeep broadcasts its GPS position as a beacon and relays operator commands.

SAFETY BY DESIGN

The flight controller keeps flying if the Jetson crashes. Arm, disarm and kill commands travel radio → flight controller directly, never through the companion computer.

SHEET 03

Line Simulator

404-Engineering/line_simulator ↗

A physics-based simulator for packaging and filling lines. Conveyors, photoeyes, motors, accumulation tables and bottles are prebuilt Godot components; a line is assembled in the editor from layout drawings and measured dimensions. Real or emulated Allen-Bradley Logix PLCs drive the virtual line over EtherNet/IP, and batch runs measure throughput, cycle times and bottlenecks per bottle format. Runs natively on macOS.

≥ 500bottles stable at ≥ 100 Hz
≤ 20 msPLC round-trip, polling
± 5 %throughput vs. real line

Roadmap

  1. P0SpikeOne conveyor, jitter-free bottles, one photoeye; read/write a Logix tag.
  2. P1Core componentsConveyor, photoeye, motor, accumulation table, bottle spawner.
  3. P2PLC I/OPlc node with tag bindings in the Inspector; several PLCs per line.
  4. P3Metrics & batch runsThroughput, cycle time, blocked/starved time, buffer occupancy → CSV.
  5. P4Builder ergonomics@tool conveyors that redraw and snap; live I/O panel.
  6. P5Component libraryCurves, merges, diverts, machines as parameterised black boxes.
  7. P6First real lineA full line from drawings and PLC programs, validated against measured rates.
  8. P7EtherNet/IP adapterAppear to the PLC as remote I/O for scan-synchronous timing.
  9. P8Format changeoverGuide rails, format parts and changeover time as scenarios.

TOOLCHAIN Godot 4.7 · Jolt physics · GDScript · Python 3.11 · pycomm3 · uv

About

404 Engineering is run by an automation engineer who builds the tools and machines that don't exist yet. The work spans the full stack: PCB design and embedded firmware, computer vision on edge hardware, PLC integration and physics simulation.

Projects follow the same rules: a written design document before code, milestones with measurable targets, and everything in public repositories.
